# Privacy / Конфиденциальность

Этот файл описывает данные, с которыми работает актуальный исходный код DeiLaw. Он не заменяет юридическую политику конфиденциальности сервиса.

## Локальные данные

DeiLaw может хранить на компьютере пользователя локальную базу законодательства, настройки, историю поиска, историю обновлений, логи, данные памятки, черновики/историю RP-помощника, резервные копии и идентификатор установки. Эти файлы относятся к runtime-данным и исключены из Git.

## Community identity

При первом использовании Community-функций клиент создаёт случайные `installation_id` и `installation_secret` в локальном runtime-файле. На Windows клиент читает MachineGuid локально и использует его только как вход для salted SHA-256. В сетевые запросы передаётся производный hash/device ID, а не исходный MachineGuid.

## Cloud AI

Согласно `ai_core/cloud.py`, в Cloud AI отправляются:

- текущий вопрос/RP-ситуация (до 5000 символов);
- до 6 последних сообщений диалога, каждое ограничивается клиентом;
- режим запроса и точные ссылки на статьи при наличии;
- версия DeiLaw;
- installation ID и производный device ID в HTTP-заголовках.

Поиск по полной серверной базе законов выполняется в Supabase. OpenAI API вызывается backend-функцией, а не desktop-клиентом.

## Отзывы, репорты и предложения

Данные, которые пользователь сам отправляет через Community-разделы (текст отзыва, репорта, сообщения, предложения и разрешённые вложения), передаются серверу DeiLaw для соответствующей функции.

## Что не должно публиковаться в Git

Локальные `.env`, токены, пароли, пользовательские базы, identity-файлы, логи, вложения и резервные копии исключены правилами `.gitignore`.
