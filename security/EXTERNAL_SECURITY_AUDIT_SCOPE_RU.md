# Техническое задание независимому аудитору — DeiLaw

Проект: Windows DeiLaw 0.3.5rc11 + DeiLaw Support Center 0.2.4 + Supabase `ntizjwncrbokebjsfwgu`.
Тестировать в **выделенной staging-среде** с искусственными аккаунтами и данными; не разрушать боевые записи пользователей.

## Обязательная программа

1. Разграничение доступа Supabase: обычный Discord-пользователь A, B, guest и admin; перехват, переподстановка `report_id`, `owner_uid`, Discord ID, доступ к сообщениям, приватным отзывам и вложениям; проверка права на ответы/статусы в Support Center.
2. Восстановление старых записей: отрицательные тесты без секрета, с неверным секретом и с уже привязанным другим владельцем, параллельные запросы, запрет просмотра чужих сообщений.
3. Авторизация: Discord OAuth state/PKCE, redirect callbacks, хранение refresh-токена под DPAPI, принудительная отмена сессий, имитация утечки токена, смена пользователя и гарантированное отсутствие секретов в crash.log.
4. Cloud AI: prompt injection в тексте закона и в пользовательских полях, ограничения размера, квоты, перегрузка, обход JWT, защищённость сервисного OpenAI ключа.
5. Вложения: обход лимита пяти файлов, гонки, ZIP/polyglot, SVG/XSS, PNG/JPEG/WebP parser fuzzing, служебные пути, MIME spoofing, работа при недоступном ClamAV, токены сканера, анализ существующих файлов, запрет открытой публикации приватного Storage bucket.
6. Обновления: подмена GitHub Releases и JSON-манифеста, неверный SHA256/Ed25519, попытка исполнения чужого EXE, time-of-check/time-of-use, downgrades, отсутствие сети, проверка Authenticode Windows Trust API, UAC, сохранение настроек при обновлении.
7. Автоматизация: SAST, dependency audit, SBOM, license review, динамическое сканирование работающего EXE на Windows 10/11 и Support Center, анализ сторонних AHK макросов.
8. Disaster recovery: зашифрованный pg_dump + Storage objects на независимом хранилище, целостность, полное восстановление только в staging, проверка RTO/RPO и смены секретов.
9. Сетевые и веб-запросы: SSRF и DNS rebinding на загрузке Устава, перенаправления, ограничения файлов, сертификаты HTTPS, сетевые таймауты.
10. Проверить CAPTCHA/Turnstile и защита администраторского пароля (с MFA), антибот на группах свежих/гостевых аккаунтов и IP лимиты.

## Ожидаемые доказательства

- Отчёт со списком находок (CWE/CVSS, шаги воспроизведения, влияние, уровни риска).
- Верифицированный список исправлений со снимками тестов и версиями бинарных файлов.
- Сертификат/акт исполнителя, подтверждающий объём, методологию и границы тестирования, **но не обещание отсутствия неизвестных уязвимостей**.
- Повторное тестирование каждой существенной находки и решение о готовности выпуска.

Публичный Supabase/production или Discord реальные аккаунты нельзя использовать для разрушительных тестов без отдельного разрешения владельца. Входящие в этот ZIP автотесты не заменяют независимую проверку.
