DeiLaw 0.3.0 — Cloud AI

• AI переведён с локального Ollama/Qwen на Cloud AI через Supabase Edge Function.
• OpenAI API key не хранится в desktop-клиенте и задаётся только в secrets backend.
• Для Cloud AI используется серверная база законодательства и возврат использованных источников.
• Локальные Ollama/Qwen больше не требуются.
• Обычный поиск, памятка и калькулятор продолжают работать независимо от Cloud AI.
