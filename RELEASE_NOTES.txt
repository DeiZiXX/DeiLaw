DeiLaw 0.3.5rc10 — Update Modes / Signed Auto Update

Новый выбор режима установки обновлений:
• Автоматически — устанавливать проверенный подписанный релиз без дополнительных вопросов.
• Спрашивать перед установкой — выбор по умолчанию для существующих пользователей.
• Только уведомлять — показывать доступную новую версию, не скачивая её.

Важно: в исходниках нет доверенного публичного ключа подписи. Без его установки автоматическая
загрузка/установка отключена. Система не должна запускать непроверенный файл.
Запуск автоматического установщика поддерживается только в установленной Windows-версии
(Inno Setup), после проверки Ed25519 подписи manifest, SHA-256 и размера EXE.
Портативный запуск из dist/DeiLaw и исходников по-прежнему не умеет обновляться автоматически.
Подробности: UPDATE_RELEASE_SETUP_RU.md.
