DeiLaw 0.3.5rc8 — автоматическая привязка старых отзывов и репортов к Discord

- После входа Discord фоновый безопасный перенос прежних данных по доказательству установки.
- Срабатывает и при восстановлении сохранённой Discord-сессии.
- Никогда не присваивает гостю старые записи.
- Сохраняет старые отзывы и репорты; переносит переписку с репортами.
- Одно подтверждённое Discord-имя у отзыва без ручного поля.
- При наличии нового отзыва старый не перезаписывается.
- 52 теста Python прошли; проверка реального входа на Windows требуется.
- Серверная миграция уже установлена на рабочем Supabase.

Внимание: папка data от предыдущего приложения должна сохраниться!
Если архив распакован в новую папку, перенесите community_identity.bin
(либо community_identity.json у старых установок) из собственной старой
папки data в новую перед первым запуском.
