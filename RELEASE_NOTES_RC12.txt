DeiLaw 0.3.5rc12 — Auth CAPTCHA integration + security deployment

- Одноразовая Turnstile CAPTCHA для новой гостевой регистрации при настроенном публичном sitekey.
- Публичный sitekey не заменяет секрет Turnstile в Supabase. До настройки боевого провайдера CAPTCHA не активирована.
- Готовый вариант развёртывания AV на собственном Linux VPS: Docker Compose, ClamAV, Caddy HTTPS без хостинг-плагинов.
- Более жёсткая health-проверка ClamAV: отсутствующий clamscan/устаревшие базы -> отказ.
- Руководство SECURITY_DEPLOYMENT_RC12_RU.md по бэкапу, цифровой подписи, CAPTCHA, ClamAV, независимому аудиту.
- Поддержка и лимиты действующего Supabase не переустанавливаются при обновлении исходников.
- 90 unit/contract тестов на Linux. Windows exe не проверен.
- Вложения по-прежнему заблокированы сервером до реального подключения AV-сервера (fail-closed).

ВАЖНО: это исходники, а не подписанный/сертифицированный релиз. Не запускайте старые SQL-модули поверх рабочего Supabase.
