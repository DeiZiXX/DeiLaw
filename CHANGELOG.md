# Changelog

## 0.3.4

- Публичные ответы разработчика на отзывы с отображением даты/времени МСК.
- «Предложить идею» и «Мои предложения».
- Статусы предложений: Новое → Рассматривается → Запланировано → Реализовано / Отклонено.
