# Верификация DeiLaw

Этот документ предназначен для модератора/верификатора, которому нужно быстро проверить проект и понять, что именно находится в репозитории.

## 1. Исходный код

Исходный код desktop-приложения опубликован в корне репозитория. Основная точка входа — `main.py`, основной интерфейс — `ui/main_window.py`.

Ключевые части проекта:

- `database.py`, `parser.py`, `article_parser.py`, `update_worker.py` — локальная база законодательства и её обновление;
- `search_lexicon.py` — умный поиск и подсказки;
- `gibdd_charter.py` — Устав УГИБДД;
- `ai_core/` и `ai_worker.py` — Cloud AI client-side logic и обработка источников;
- `community_client.py` — отзывы, репорты, предложения и client identity;
- `updater.py` — обновления приложения через GitHub Releases;
- `supabase/functions/deilaw-ai/index.ts` — исходный код Cloud AI Edge Function;
- `SUPABASE_SETUP.sql` и `SUPABASE_CLOUD_AI_SETUP.sql` — схема/политики серверной части, публикуемые без секретных ключей.

## 2. Версия

Текущая версия исходников задаётся в `app_version.py`:

```python
APP_VERSION = "0.3.4"
```

## 3. Что делает программа

DeiLaw предназначен для работы с законодательством RMRP. Основные функции: локальная база и обновление законов, точный и текстовый поиск, просмотр документов, Устав УГИБДД, персональная памятка, F7/F8/F9 Quick-окна, калькулятор наказаний, Cloud AI, история обновлений, отзывы, репорты/чат, предложения пользователей, темы/звуки, автообновление приложения и диагностика.

Полное описание функций находится в корневом `README.md`.

## 4. Cloud AI и секреты

Desktop-клиент не содержит `OPENAI_API_KEY`. Он обращается к Supabase Edge Function `deilaw-ai`. OpenAI key и серверные Supabase secret/service keys должны задаваться только в окружении backend.

В репозитории присутствует Supabase publishable key, который используется клиентом для обращения к публичному API. Это не серверный secret key.

## 5. Что отправляет Cloud AI клиент

По текущему клиентскому коду Cloud AI получает:

- текст текущего вопроса/RP-ситуации;
- до 6 последних сообщений истории чата;
- режим запроса и точные ссылки на статьи, если они есть;
- ID установки;
- односторонний хэш ID устройства;
- версию приложения.

Серверная функция ищет релевантные нормы в серверной базе законодательства и передаёт модели ограниченный контекст.

## 6. Проверка исходников

Из корня репозитория:

```bash
python scripts/verify_source.py
```

Проверка не запускает приложение и не делает сетевых запросов. Она компилирует Python-файлы, проверяет наличие ключевых компонентов и ищет типовые случайно опубликованные секреты.
