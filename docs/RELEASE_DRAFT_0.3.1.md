## О DeiLaw

DeiLaw — независимый Windows-помощник для пользователей RMRP. Позволяет искать нормы игрового законодательства, работать с памяткой и калькулятором наказаний, использовать быстрые окна F7/F8/F9, при желании подключать Cloud AI и функции сообщества.

**Неофициальное приложение, не связанное с администрацией RMRP.** Исходные юридические тексты RMRP, их товарные знаки и сторонние сервисы не принадлежат DeiLaw и не перелицензируются на GPL.

## Основные особенности будущего GPL-релиза

- Исходный код собственной части DeiLaw под GNU GPL-3.0-only, полный LICENSE и явные границы лицензирования.
- Windows-установщик NSIS с просмотром лицензии и уведомления о приватности.
- Три необязательные фоновые сетевые функции выключены по умолчанию при новой установке.
- Сохранение пользовательской папки `data/` при повторной установке и удалении в автоматических Windows-тестах.
- Реестр лицензионных уведомлений поставляемых Python wheels и SHA-256 контрольная проверка.
- Доступен архив соответствующего **собственного** исходного кода `DeiLaw_Source_v0.3.1.zip` и манифест происхождения `source_provenance.json`.
- Подготовлен процесс подписания SignPath, но **одобрение SignPath и Authenticode не получены**.

## Перед установкой

1. Сохраните резервную копию пользовательских `data/` и `community_identity.bin`, не отправляя их другим лицам.
2. Если прежняя версия установлена через Inno Setup (`unins000.exe`), новая NSIS-сборка **не перезаписывает** её автоматически. Сначала создайте резервную копию, затем удалите старую версию и отдельно установите новую.
3. Для облачных функций нужны соответствующие сетевые разрешения и сервисы. Политика: [PRIVACY.md](../PRIVACY.md).

## Автоматизированный выпуск — только как черновик

В PR подготовлен [manual GPL draft release workflow](../.github/workflows/gpl-release-draft.yml). **После** подтверждения прав, третьих библиотек, интерактивной Windows-проверки и слияния проверенного PR в `main` владелец может открыть GitHub Actions и вручную запустить этот workflow из `main`.

Workflow блокирует запуск без `rights_and_licenses_checked=true` и полного SHA `reviewed_commit_sha`, равного собираемому коммиту. Запускает сборку и установочные тесты, сверяет SHA-256 установщика и source archive, затем создаёт только **DRAFT GitHub Release** с неподписанными артефактами. Автоматически открыто не публикует.

Настройка защищённой GitHub environment `gpl-release` с доверенными reviewer обязательна перед ручным запуском. Только после ручной проверки опубликованного OSS-релиза возможна отдельная [SignPath Foundation application](https://signpath.org/apply.html).
