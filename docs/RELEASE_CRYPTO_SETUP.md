# DeiLaw — безопасный выпуск подписанных обновлений (после SignPath)

Это **не цифровая подпись SignPath**. Ed25519 защищает манифест `update_manifest.json`, а Authenticode подтверждает издателя Windows-EXE. Для официального релиза нужны **обе проверки**. В подготовительной ветке `UPDATE_ED25519_PUBLIC_KEY_B64` по-прежнему пустой; проверка обновлений отказывает по умолчанию.

## Выполняется только владельцем на автономной Windows-машине

1. Убедитесь, что актуальный GPL/SignPath релиз готов, код и зависимости проверены, приватные ключи не хранятся в GitHub и облаках.
2. Подключите защищённый офлайн-носитель и откройте PowerShell **без сетевого подключения**. В папке исходников (с установленным `cryptography`) выполните:
   ```powershell
   python scripts/create_offline_update_key.py "E:\\SecureKeys\\DeiLaw_Update_Ed25519.pem"
   ```
   Скрипт спросит длинную парольную фразу дважды и создаст зашифрованный PKCS#8 Ed25519 ключ **вне репозитория** с режимом «не перезаписывать».
3. Сохраните приватный файл на офлайн-носителе и сделайте физически отдельную резервную копию. **Никому не передавайте приватный ключ и пароль**, включая AI-чат, GitHub Issues/Actions и SignPath.
4. Скрипт выведет **только публичную** base64-часть. Вставьте её в `UPDATE_ED25519_PUBLIC_KEY_B64` в `update_trust.py`, коммитьте public-only изменение через PR и пересоберите приложение. Не активируйте автоматические обновления в старом бинарнике, где публичный ключ пуст.
5. После официальной SignPath-подписи установщика создайте манифест, а затем подпишите его **на автономной машине**:
   ```powershell
   python scripts/create_update_manifest.py 0.3.1 "DeiLaw_Setup_v0.3.1.exe" "update_manifest.json"
   python scripts/sign_update_manifest.py "E:\\SecureKeys\\DeiLaw_Update_Ed25519.pem" "update_manifest.json"
   ```
   Пароль спрашивается локально, а поле `mandatory` входит в Ed25519-подпись; его изменение после подписи запрещено. Указанная версия — только пример для исходного кода 0.3.1, перед реальным релизом сверяйте её с `app_version.py`.
6. Выполните проверку `verify_manifest` и SHA-256 подписанного установщика; затем опубликуйте манифест вместе с **тем самым** подписанным setup и source archive/tag. Нельзя изменять подписанный установщик после вычисления хеша.

## Не выполнено автоматически

Приватный ключ **не создан** и **не должен создаваться на GitHub runner**. Не подтверждены SignPath approval, секреты, подписанные артефакты, политики и ручной выпуск. Запрос MFA и создание API-токена доступны только в аккаунтах владельца. Скрипт лишь делает безопасным последующее действие владельца.

Используйте [SIGNPATH_FINAL_GATE.md](SIGNPATH_FINAL_GATE.md) и [SIGNPATH_APPLICATION_DRAFT.md](SIGNPATH_APPLICATION_DRAFT.md) для общего релизного допуска.
