# Проверка RP-биндера DeiLaw 0.3.5rc1 в RMRP

Это тестовая версия исходников, а не готовый Windows-установщик. Не удаляйте
установленную DeiLaw v0.3.4: сохраните резервную копию пользовательских данных.

## Запуск тестовой версии

1. Распакуйте архив в отдельную папку, например `DeiLaw-v0.3.5rc1-test`.
2. Если установлен Python 3.11+, запустите `START_BINDER_TEST.bat` двойным
   щелчком. Он создаст локальное окружение, установит зависимости и откроет
   тестовую DeiLaw. Также можно выполнить команды вручную:
   `python -m pip install -r requirements.txt`, затем `python main.py`.
4. В DeiLaw откройте «AHK бинды для RP», добавьте временный бинд на свободное
   сочетание клавиш и одну безопасную RP-команду (`/me проверяет жетон`).
5. Убедитесь, что внизу страницы написано «RP-бинды DeiLaw активны: 1/1»
   (или соответствующее число зарегистрированных биндов).
6. Запустите RMRP в оконном режиме без рамок, с закрытым игровым чатом;
   нажмите сочетание и через Alt+Tab проверьте строку «Последняя попытка» в DeiLaw.

## Как понять результат

- Нет строки «горячая клавиша сработала» — Windows не доставила событие
  глобальной клавиши. Попробуйте другое сочетание, не занятое RMRP или Windows.
- Есть сообщение «Windows не приняла...» — событие было обнаружено, но
  синтетический ввод не принят Windows. Проверьте, не запущена ли игра с более
  высокими правами, чем DeiLaw.
- Есть «строк передано Windows», но в чате ничего нет — Windows приняла события,
  однако игровой клиент мог их проигнорировать. Это не подтверждение отправки
  текста на сервер. Сравните с экспортированным AHK v2-скриптом и сообщите
  результаты обоих способов.
- Текст появился, но обрывается — увеличьте паузу открытия чата и задержку
  между RP-строками. Приложите пример команды и фактический результат.
- RP-строка отправляется, но чат остаётся открытым — включите на странице
  AHK-биндов галочку «Закрывать чат Esc». Если после отыгровки начнёт
  открываться меню паузы GTA, отключите эту галочку: на вашем клиенте Enter
  уже самостоятельно закрывает чат.

**Важно:** используйте только разрешённые сервером текстовые RP-макросы.
Не используйте биндер для автоматизации стрельбы, боя, езды или получения
игрового преимущества.

Тест выполняется на Windows с запущенной RMRP; автоматические проверки в
среде разработки не могут подтвердить доставку клавиш внутрь игры.
