# DeiLaw v0.3.1 — исходный код / Source code release (GPL-3.0-only)

**Первый открытый выпуск исходного кода DeiLaw для Windows.**

Этот выпуск предназначен для изучения исходного кода, самостоятельной сборки и дальнейшей разработки. **Это не новый подписанный установщик Windows.** Прежние закрытые выпуски `v0.3.0` и ранее не перелицензируются задним числом.

## Что входит

- Собственный исходный код DeiLaw 0.3.1 (Python/PyQt6), интерфейс, игровые Quick-окна F7/F8/F9 и компоненты поиска норм.
- Исходники облачного взаимодействия и Supabase Edge Functions без серверных секретов.
- NSIS-сценарий установщика, сценарии Windows-сборки и проверки качества.
- Иконки, фоновые изображения и звук, созданные для DeiLaw, в пределах прав правообладателя.
- `LICENSE` (GNU GPL-3.0-only), `LICENSE_SCOPE.md`, `THIRD_PARTY_NOTICES.md`, `PRIVACY.md` и `CODE_SIGNING_POLICY.md`.

## Основной функционал

Умный поиск по игровому законодательству RMRP, просмотр статей, локальная база законов, калькулятор штрафов и наказаний, памятка, быстрые окна F7/F8/F9, обновление законов, Cloud AI через Supabase и отзывы/репорты/предложения пользователей. Некоторые функции требуют настроенных внешних сервисов и подключения к интернету. DeiLaw — независимый проект, не связанный с владельцами RMRP.

В новый публичный архив не входят внутренние отчёты о рабочем развёртывании и административная утилита синхронизации. Исходники самого приложения, его компонентов и необходимые лицензии остаются доступны. [Политика безопасной публикации](PUBLIC_SOURCE_SECURITY.md). ## Сборка на Windows

Для запуска из исходников установите Python 3.13 (или совместимую версию), затем:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Для создания неподписанного Windows-кандидата с установленным NSIS:

```powershell
.\scripts\build_signpath_candidate.ps1
```

Автоматические Windows-тесты ранее подтвердили успешные 118/118 проверок исходников и smoke-test установки/удаления: [GitHub Actions #44166176466](https://github.com/DeiZiXX/DeiLaw/actions/runs/44166176466). Это подтверждает только протестированный коммит; при новом `main` результаты надо проверить повторно.

## Важно о Windows EXE и SignPath

**Этот выпуск содержит исходный код, а не подписанную программу.** SignPath Foundation не выдавал DeiLaw одобрение или сертификат, подпись Authenticode не получена. Соответствие лицензиям поставляемых Qt/Windows DLL, право замены LGPL-библиотек, финальная проверка установщика и отдельное оформление подписанного бинарного релиза остаются в работе. Не размещайте тестовые неподписанные сборки как официально подписанные.
