# Contributing

Спасибо за интерес к DeiLaw.

Для ошибок создавайте Issue с версией DeiLaw, шагами воспроизведения, ожидаемым/фактическим поведением и релевантным логом без персональных данных. Для предложений описывайте задачу, сценарий использования и ожидаемый результат.

Перед Pull Request:

```bash
python scripts/verify_source.py
```

Не добавляйте в коммит runtime-данные, пароли, токены, `.env`, пользовательские базы и логи.

## Лицензионные условия для вкладов

Предлагая pull request, подтверждайте, что вы написали код сами либо имеете право предоставить вклад на условиях **GPL-3.0-only**. Не копируйте в репозиторий чужие файлы из проектов с несовместимой лицензией, товарные знаки, закрытые ключи, приватные игровые материалы. Если использован сторонний код, указывайте источник, авторство, совместимую лицензию и требуемые уведомления.

PR не требует передачи авторских прав владельцу DeiLaw: автор сохраняет свои права и предоставляет вклад в проект под GPL-3.0-only. Изменения лицензионных файлов и выпуска подписи требуют отдельного ревью.
