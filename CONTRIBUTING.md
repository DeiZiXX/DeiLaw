# Contributing

Спасибо за интерес к DeiLaw.

Для ошибок создавайте Issue с версией DeiLaw, шагами воспроизведения, ожидаемым/фактическим поведением и релевантным логом без персональных данных. Для предложений описывайте задачу, сценарий использования и ожидаемый результат.

Перед Pull Request:

```bash
python scripts/verify_source.py
```

Не добавляйте в коммит runtime-данные, пароли, токены, `.env`, пользовательские базы и логи.
