# DeiLaw — безопасные автоматические обновления

## Что работает в 0.3.5rc10

- Каждый запуск: проверка GitHub Releases для канала Stable или Beta.
- В работе: опрос каждые 3 минуты.
- Настройки → Обновления программы → Установка обновлений:
  1. Автоматически (самостоятельно скачать/установить/перезапустить)
  2. Спрашивать перед установкой (по умолчанию)
  3. Только уведомлять.
- Для установки нужно совместимое официальное приложение, установленное через Inno Setup;
  EXE, запущенный из распакованного dist/DeiLaw, не позволяет тихо заменить себя.
- До запуска установщика проверяется Ed25519 подпись JSON-манифеста, совпадение имени,
  версии, SHA-256 и точного размера файла, его путь в LocalAppData и GitHub URL.
- Нет ключа, не совпал SHA-256 или подпись, не установлен официальный Inno Setup релиз:
  установка отклоняется, DeiLaw продолжает работать на текущей версии.

## Что должен сделать владелец проекта до распространения

1. Создать пару Ed25519 ключей в защищённом офлайн окружении. Приватный ключ
   никогда не загружать в GitHub, Supabase, чат или архив с исходниками.
2. Поместить BASE64 **публичного** ключа в `update_trust.py` константу
   `UPDATE_ED25519_PUBLIC_KEY_B64`, затем пересобрать DeiLaw и Windows installer.
3. Приобрести сертификат Authenticode и подписать Windows EXE/установщик в системе
   выпуска релизов. Проверить подпись и репутацию Windows SmartScreen.
4. В GitHub репозитории DeiZiXX/DeiLaw публиковать в одном релизе
   `DeiLaw_Setup_v<версия>.exe` и `update_manifest.json`.
5. Создать манифест `python scripts/create_update_manifest.py VERSION installer.exe update_manifest.json`.
6. На изолированной машине подписать манифест:
   `python scripts/sign_update_manifest.py /secure/offline_private_key.pem update_manifest.json`.
7. Проверить канал Stable/Beta, подписанные и неподписанные манифесты,
   неверный хэш, подменённый файл, отсутствие сети, работу UAC и повторный запуск Windows.
8. Тестировать с 2 разными Windows-аккаунтами. Пользовательские настройки и данные
   должны пережить установку. Содержимое `data` должно оставаться на диске.

**До выполнения этого списка автоматическая установка реально НЕ АКТИВНА**, даже если
выбран режим «Автоматически». Кнопки/настройки лишь подготавливают поведение.
